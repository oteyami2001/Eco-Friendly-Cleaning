# Ecofriendly Cleaning — website

One-page animated website built on the **Site Immersif** template.

- Site: `ecofriendly-cleaning/` (static HTML/CSS/JS, no build step)
- Edit text and images in `ecofriendly-cleaning/content.js` only
- Photos live in `ecofriendly-cleaning/images/`

## Run locally

```bash
node .claude/serve-ecofriendly-cleaning.mjs   # → http://localhost:4385
```

To host it, upload the contents of `ecofriendly-cleaning/` to any static host (Netlify, GitHub Pages, Hostinger, …).
